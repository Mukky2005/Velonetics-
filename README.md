# Velonetics-

This is a full website built using Next.js with TypeScript. The website includes dynamic pages, responsive design, and is designed to be user-friendly. It integrates Lucid React for UI components and custom styling with CSS.

## Prerequisites
Before running this project, make sure you have the following installed:

- Node.js (v14.x or above)
- npm or yarn
- Git
# 1. Core dependencies
pnpm add react@18.2.0 react-dom@18.2.0 next

# 2. TypeScript support
pnpm add -D typescript @types/react @types/node

# 3. Tailwind CSS + PostCSS setup
pnpm add -D tailwindcss postcss autoprefixer

# 4. Common utilities
pnpm add classnames

# 5. UI Libraries and Animation (optional but based on your files)
pnpm add framer-motion @radix-ui/react-toast @headlessui/react @heroicons/react

# 6. Date handling and calendar UI
pnpm add date-fns@3.6.0 react-day-picker@8.10.1

# 7. Vaul modal support (if used in your project)
pnpm add vaul@0.9.6

# 8. Initialize Tailwind CSS config (only run once)
npx tailwindcss init -p
