# Velonetics-

This is a full website built using Next.js with TypeScript. The website includes dynamic pages, responsive design, and is designed to be user-friendly. It integrates Lucid React for UI components and custom styling with CSS.

## Prerequisites
Before running this project, make sure you have the following installed:

- Node.js (v14.x or above)
- npm or yarn
- Git
